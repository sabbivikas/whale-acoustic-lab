# Zero-cost public production

The public Whale Acoustic Lab frontend is designed as a static Vite deployment
with no serverless functions, databases, analytics add-ons, or build-time
backend URL.

## Hosted modes

### Precomputed public sample

`frontend/public/samples/dswp-1.wav` and
`frontend/src/data/dswp-1-analysis.v1.json` are deployed as static assets. The
JSON is generated by `scripts/build_public_sample.py` only from checked-in
assets and existing local scientific modules. Its provenance records the audio
SHA-256, source of the stored WhAM embedding, and that no network request or
inference was used.

### Browser-only local analysis

Uploads and microphone recordings are decoded with Web Audio. The browser
performs click estimates, trimming, coda segmentation, ICI and normalized
rhythm calculations, EC1 MSE comparison/abstention, deterministic narration,
waveform/spectrogram rendering, annotation, evaluation, and export.

This mode:

- sends no audio or analysis request;
- creates no WhAM embedding or acoustic neighbors;
- calls no OpenAI/GPT service; and
- never represents timing-derived Art View parameters as an embedding.

### Bring Your Own Backend

The Advanced panel accepts a researcher’s compatible HTTPS backend URL and
stores it only in that browser’s `localStorage`. No API key is requested or
stored. Later uploads are sent only while the researcher has explicitly kept
that connection enabled. The researcher/operator is responsible for hosting
cost, authentication, access control, model/data licenses, logs, and retention.

## Vercel configuration

- Root directory: `frontend`
- Framework: Vite
- Install command: `npm ci`
- Build command: `npm run build`
- Output directory: `dist`
- Environment variables: none
- Functions/databases/analytics: none

Deployment is permitted only after confirming the authenticated account is on
a free Hobby/static path. If Vercel requires payment or an upgrade, do not
deploy.

## Release gates

`python3 scripts/release_checks.py` rejects:

- a compiled default backend environment variable;
- any maintainer or other `.modal.run` endpoint in frontend source or bundle;
- network primitives in the browser-only analyzer;
- a missing/modified public-sample analysis or reference-data copy;
- secret/checkpoint/publication-policy violations.

The production bundle must be scanned after `npm run build`. The maintainer’s
`whale-acoustic-lab` Modal app must remain stopped, and release verification
must not call its endpoint.
